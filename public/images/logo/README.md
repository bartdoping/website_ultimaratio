# Logo-Bilder

## 📁 Dateien für diesen Ordner:

### Hauptlogo:
- `logo.png` - Hauptlogo (empfohlen: 200x200px oder größer)
- `logo-white.png` - Weißes Logo für dunkle Hintergründe
- `logo.svg` - Vektorgrafik (bevorzugt für Skalierung)

## 📐 Spezifikationen:
- **Format**: PNG oder SVG (SVG bevorzugt)
- **Größe**: Mindestens 200x200px
- **Hintergrund**: Transparent
- **Qualität**: Hochauflösend für scharfe Darstellung

## 🎯 Verwendung:
- Header-Logo
- Footer-Logo
- Favicon
- Social Media

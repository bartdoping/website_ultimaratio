## Bildanforderungen

### Technische Spezifikationen
- **Format**: JPG oder WebP
- **Auflösung**: Mindestens 1920x1080 für Desktop
- **Mobile**: 768x1024 für Mobile-Optimierung
- **Komprimierung**: 80-85% Qualität für Web
- **Alt-Tags**: Beschreibende Alt-Texte für SEO

### Stil-Richtlinien
- **Authentisch**: Echte, nicht gestellte Situationen
- **Emotional**: Gefühle und Stimmungen vermitteln
- **Divers**: Verschiedene Studenten-Typen
- **Professionell**: Hochwertige Aufnahmen
- **Konsistent**: Einheitlicher Farbstil

## Stock-Foto Quellen
- **Unsplash**: Kostenlose, hochwertige Fotos
- **Pexels**: Zusätzliche Stock-Fotos
- **Keywords**: "medical student", "study stress", "exam preparation", "tutoring"
